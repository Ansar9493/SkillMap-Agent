# SkillMap-Agent
AI-powered career intelligence agent using LangChain and Gemini


## 📌 Project Overview

SkillMap Agent is an AI-powered career intelligence assistant that helps users understand industry demand for specific skills and discover relevant job opportunities in India.

## ✨ Features

- Industry skill-demand research
- Salary insights and career trends
- Relevant job opportunity discovery
- AI-powered tool orchestration

## 🛠️ Tech Stack

- Python
- LangChain
- Google Gemini
- Tavily Search
- JSearch API (RapidAPI)
- Google Colab

## 🧠 How It Works

1. User submits a skill-related query.
2. Gemini-powered agent understands the request.
3. Tavily researches industry demand and career insights.
4. JSearch API retrieves relevant job listings.
5. The agent combines the results into a response.

## 💻 How to Run

1. Open the notebook in Google Colab.
2. Install the required dependencies.
3. Configure API credentials using Google Colab Secrets.
4. Run the notebook cells.
5. Enter your skill-related query.

## 🔐 API Configuration

Configure these credentials securely:

- `GOOGLE_API_KEY`
- `TAVILY_API_KEY`
- `RAPIDAPI_KEY`

Never publish API keys in your repository.
